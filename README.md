# React Portfolio

A modern portfolio website built with React, Vite, Tailwind CSS, and React Router.

## 🚀 Getting Started

### 1. Install dependencies
```bash
npm install
```

### 2. Run locally
```bash
npm run dev
```

### 3. Build for production
```bash
npm run build
```

### 4. Preview production build
```bash
npm run preview
```

## 🌐 Deployment

### Netlify
Add a `_redirects` file in `public/` with this content:
```
/*    /index.html   200
```

### Vercel
Just push to GitHub and import your repo on [Vercel](https://vercel.com).

## 📂 Project Structure
- `src/components` → Navbar, Footer
- `src/pages` → Home, About, Portfolio, Contact
- `src/pages/portfolio` → Icons, Illustrations, Patterns, 3D

## ✉️ Contact Form
The Contact page uses [Formspree](https://formspree.io/).  
Replace `https://formspree.io/f/your-form-id` with your own endpoint.
